# 基准样本来源与许可

本目录的样本与规则集由 VoxWard 项目为基准测试原创合成。它们不来自任何真实观众、平台或第三方数据集。

## 来源与合法性

| 项目 | 说明 |
| --- | --- |
| 来源类别 | 合成（synthetic-authored），由 VOXWARD-SUB-049 实施者手工撰写 |
| 真实观众数据 | 不含（`contains_real_viewer_data: false`） |
| 平台数据 | 不含；不抓取 YouTube，不复制任何直播聊天室内容 |
| 第三方数据集 | 不使用。若将来引入，须先在本文件登记来源、许可证和引用范围 |
| 许可 | 与本仓库相同。仓库根目录目前没有 LICENSE 文件，因此仅限项目内部使用 |
| 占位词 | 禁词甲、禁語乙、禁語丙、bannedalpha、badword、扣分词丁。它们只是规则测试的占位，不是侮辱词表 |
| 数据范围 | 每条样本都是短句，昵称也是虚构的 |

## 期望标签的含义

每条样本有两组期望值，二者分别代表不同层的真值：

- `expected.route`：规则层的真值。输入是完整消息（昵称加正文）。它表示占位规则集应当给出的路由（PASS、BLOCK 或 REVIEW）。规则引擎不理解语境，所以学术引用「badword」也是 BLOCK。
- `expected.ai`：AI 分类层的真值。输入只有正文，与合同一致（模型只收到临时条目编号与正文）。它表示人工对正文的分类（ALLOW_MEANINGFUL、ALLOW_NOISE 或 BLOCK）。仅由昵称造成的违规，正文本身是放行的，因此 `expected.ai` 为放行。
- `joint`：跨条线程的整体期望。引擎逐条判定，因此 `joint` 不计入分数，只计数为「未测」。

期望值依据政策意图人工设定，不依据运行结果回填。
