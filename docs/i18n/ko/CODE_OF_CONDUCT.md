# 행동 강령

[English](../../../CODE_OF_CONDUCT.md) · [简体中文](../zh-CN/CODE_OF_CONDUCT.md) · [日本語](../ja/CODE_OF_CONDUCT.md) · **한국어** · [Français](../fr/CODE_OF_CONDUCT.md)

## 우리의 서약

지역, 언어, 배경, 정체성 또는 경험 수준에 관계없이 모든 기여자와 사용자에게 존중과 포용이 보장되는 괴롭힘 없는 VoxWard 참여 환경을 유지할 것을 약속합니다.

## 권장 행동

- 지원되는 5개 작업 언어(`en`, `zh-CN`, `ja`, `ko`, `fr`) 전반에서 건설적으로 소통합니다.
- 선의를 가정하되 기술적 주장은 재현 가능한 근거에 기반하여 논의합니다.
- 프라이버시를 보호합니다: 시청자 닉네임, 비공개 메시지, 자격 증명 또는 개인 연락처를 공개하지 않습니다.
- 개인에 대한 공격이 아니라 코드, 계약, UX 및 안전성에 피드백을 집중합니다.

## 금지되는 행동

괴롭힘, 위협, 신상 털기(doxxing), 차별적 발언, 부적절한 성적 표현, 논의 및 리뷰 절차의 의도적 방해는 허용되지 않습니다.

## 집행 및 비공개 제보

행동 강령 위반 우려 사항은 공개 Issues 나 Pull Requests 에 비난이나 사적 정보를 게시하지 말고 저장소 관리자(`tpmoonchefryan`)에게 비공개로 전달해 주세요.

관리자는 안전 및 법적 요구 사항을 고려해 문제 콘텐츠 수정·삭제, 논의 종료 또는 접근 제한 등의 조치를 신중하게 취할 수 있습니다.

> 보안 취약점은 행동 강령 채널이나 공개 이슈가 아니라 [GitHub Private Vulnerability Reporting](../../../SECURITY.md) 을 통해 제보해 주세요.
