# 行为准则

[English](../../../CODE_OF_CONDUCT.md) · **简体中文** · [日本語](../ja/CODE_OF_CONDUCT.md) · [한국어](../ko/CODE_OF_CONDUCT.md) · [Français](../fr/CODE_OF_CONDUCT.md)

## 我们的承诺

我们致力于为所有参与 VoxWard 的贡献者与使用者提供尊重、包容、无骚扰的协作环境，无论其地区、母语、背景、身份或经验水平如何。

## 期望行为

- 在项目支持的五种工作语言（`en`、`zh-CN`、`ja`、`ko`、`fr`）中保持建设性沟通。
- 善意推定他人意图，同时用可复现的证据与结果讨论技术判断。
- 尊重并保护隐私：不在讨论中公开观众昵称索引、私密消息、密钥凭据或个人联系方式。
- 意见聚焦于代码、契约、用户体验与安全边界，而非人身评价。

## 不可接受的行为

严禁骚扰、恐吓、人肉检索（doxxing）、歧视性言论、不当性暗示内容，以及恶意破坏讨论或评审秩序的行为。

## 执纪与私密投诉

如遇违反本准则的情况，请私下联系仓库维护者（`tpmoonchefryan`），切勿在公开 Issue 或 Pull Request 中挂人、公开争吵或披露隐私材料。

维护者有权视情节编辑或移除不当内容、关闭讨论或限制仓库协作权限，并在兼顾安全与合规的前提下审慎处理投诉。

> 安全漏洞请通过 [GitHub 私密漏洞报告](../../../SECURITY.md) 提交，勿走行为准则或公开 Issue 渠道。

本准则依据 Contributor Covenant 2.1 核心原则改编，不在公开文档中硬编码个人邮箱。
