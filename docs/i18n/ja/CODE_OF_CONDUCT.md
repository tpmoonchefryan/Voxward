# 行動規範

[English](../../../CODE_OF_CONDUCT.md) · [简体中文](../zh-CN/CODE_OF_CONDUCT.md) · **日本語** · [한국어](../ko/CODE_OF_CONDUCT.md) · [Français](../fr/CODE_OF_CONDUCT.md)

## 私たちの誓約

地域、言語、背景、アイデンティティ、経験レベルを問わず、すべての参加者にとって敬意ある、ハラスメントのない開発・利用環境を維持します。

## 期待される行動

- 対応する 5 言語（`en`、`zh-CN`、`ja`、`ko`、`fr`）すべてにおいて建設的な対話を心がけること。
- 善意を前提とし、技術的な指摘は再現可能な根拠に基づいて行うこと。
- プライバシーを尊重し、視聴者のハンドルネームや私的メッセージ、認証情報、個人連絡先を共有しないこと。
- 個人への攻撃ではなく、コード・仕様契約・UX・安全性に議論を集中させること。

## 許容されない行動

ハラスメント、脅迫、個人情報晒し（doxxing）、差別的発言、不適切な性的表現、議論やレビューの意図的な妨害は容認されません。

## 運用と非公開での報告

行動規範に関する懸念は、パブリックの Issues や Pull Requests に個人情報や非難を公開せず、リポジトリメンテナー（`tpmoonchefryan`）へ非公開で報告してください。

メンテナーは安全性および法的要件に配慮しつつ、必要に応じて投稿の編集・削除、議論の終了、アクセス制限等の適切な措置を講じます。

> セキュリティ脆弱性については行動規範窓口や公開 Issue ではなく、[GitHub Private Vulnerability Reporting](../../../SECURITY.md) をご利用ください。

本ポリシーは Contributor Covenant 2.1 の原則に基づき作成されており、個人の連絡先メールアドレスは公開していません。
