# VTube Studio (VTS) 接入调研与限制说明

结论：**不支持无本地插件/代理直连**（依据 `VW-S024-AC001` 与提案 §13.2）。

## 1. 技术限制与拓扑原因

1. **本机运行限制**：VTube Studio 插件 API 仅在**主播 PC 本机**运行并接受本地授权连接，远端自托管的 VoxWard 服务器无法在无本机代理的情况下直连主播本机 VTS 实例。
2. **MVP 范围边界**：本项目不开发专门的本机代理或本地 VTS 插件，也不把服务端作为本机插件宿主。

## 2. 替代方案与安全约束

- **仅由 OBS / 浏览器消费只读事件**：主播应使用 VoxWard 原生 OBS Overlay（`/overlay/:roomId`）或 `blivechat-v1.x-json-ws` 兼容输出，在 OBS / 浏览器侧消费只读、可撤销（`4403`）事件。
- **第三方桥接工具**：若主播自行评估第三方工具（如 Streamer.bot 等）承接远端只读事件并控制本机 VTS，属主播本机自建链路，**未在本项目联调验证，不标为官方支持**。
